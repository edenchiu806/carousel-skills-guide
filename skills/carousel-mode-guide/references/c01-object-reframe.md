# C01 你以為／其實：單物件對照

以固定左右短標題、同一品項的實際狀態，讓讀者重新判斷一件日常的事。前段每張獨立成立、反覆支持同一個新標準；後段在圖片內完成標準、生活價值與CTA。不是通用逐頁故事稿，也不是只做大小或數量差。

製作時讀 [你以為／其實單物件輪播 skill](../../misconception-object-carousel/SKILL.md)，它是本模式的詳細正式來源，本安裝包已一併附上，不需原私人工作區。

前段標題跨張固定，但不必逐字使用「你以為／其實」；「這不叫浪費／這才是」也屬同一閱讀機制。物件要直接對應判斷，caption只補來源與條件，不能挽救看不懂的比喻。後段可用短文字收束，不必死守左右兩欄。

2026-11-17依使用者更正，C01已取代舊版通用「逐頁觀點／故事」。一般寫作方法仍可作支援，不再當作本套八種風格之一。
