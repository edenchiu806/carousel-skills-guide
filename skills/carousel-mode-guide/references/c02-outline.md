# C02 短鉤子＋跨頁大綱

適合一個能拆成數個面向的主題，讓讀者先看全貌，再逐項理解。原參考曾用「關鍵字＋是」作未完成定義；後來已改為受眾內心話的短鉤子，不固定使用定義句。

## 製作思維

先找受眾還沒做到哪一步、想得到什麼、在意什麼代價。分項標題用他會問的問題，不直接搬作者的專業分類。第一頁用短鉤子、固定 IP 人物、留白和向右延伸的線；第二頁由左邊接同一條線，分成大綱。正文按大綱依序解說，最後由全貌推出作者立場及下一步。

第一二頁先一起完成，再做內頁。兩頁並排，接線的高度、線寬與顏色必須吻合，分支與節點也同色。不是分別畫兩條大概相似的裝飾線。第二頁的大綱名稱、數量及順序直接對應正文，不塞各項長解釋。

## 外觀與最新設定

本模式既有要求使用深色純底，不用白、奶油白、米白或近白底。封面優先試八字內短鉤子，仍以語意完整與當次指示為準。深底白字時接線也白。人物沿用同一實際資產，不每頁重生成求相似；身份未確認的角色不宣稱是本人。

內頁簡約，通常一個標題與必要短段落即可。例子與判斷直接放段落，不預設堆章節編號、進度條、分隔線、獨立金句和多層字體。張數由分項需要決定。

原任務 2026-11-14 最新外觀已是純黑 #000 底、純白 #fff 字與線、黑白人物，取代較早深藍橘字版。這是沿用原成品時的設定；新品牌不自動套原主題、人物或 CTA。當次新指示可覆寫外觀，不能拿舊橘字要求蓋過新指示。

## 檢查

封面只有一個文字焦點，沒有長承諾或提前塞目錄；首兩頁連線精準；大綱與正文逐項對上；人物資產相同；內頁沒有膨脹成課綱卡。不要用故事型前導、攝影大場面或上下雙圖替代已選模式。
