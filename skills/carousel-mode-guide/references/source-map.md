carousel-production 是接帳號、受眾、素材、製作與交付的共用入口，不另算一種模式。text-carousel-writing 同時承擔一般寫作與數種歷史模式文件，也不能整個當成唯一的「文字模式」。

來源重整時保留三層：本技能管選型；專門技能管詳細製作；帳號 profile 與當篇資料管聲音、配色、角色、主題及 CTA。不把所有標準搬到入口維護第二套。

本包是可獨立使用的蒸餾版，不是原工作區完整備份。未包含私人記憶、Podcast 原文庫、成品圖片、字型、帳號登入、生圖服務或匯圖引擎。原來源保留的研究紀錄與舊版否決不全量攜出；關鍵製作約束已寫進對應模式。

1.1.0依使用者更正，以「你以為／其實單物件對照」取代1.0.0的C01通用逐頁寫作。新skill整合先前單物件固定標題工作流及後續修正：不用抽象比喻補救、不只大小差異、允許必要狀態標籤、同品項必要數量、圖內價值觀與CTA，以及整組內容縮小置中。一般逐頁寫作仍保留為支援能力，不是第九種風格。

C02 的 source reference 仍記載較早橘字版，因此另核對 podcast-carousel-production 任務狀態的2026-11-14黑白v7更新；本包明確保留版本差異，避免把歷史範例當最新設定。
