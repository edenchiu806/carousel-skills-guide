# 你以為／其實：單物件對照輪播

這套模式對應八模式指南 C01。用日常品項直接檢查一個原本習慣的判斷：同樣是花錢、練習或使用，什麼狀態才真正符合我們在意的標準？前段讓物件提供辨認，重複標題減少重新學讀法的負擔；後段說清新標準、適用條件及下一步。

「你以為／其實」是模式名稱，不要求每張逐字放這六個字。可用「這不叫浪費／這才是」等直接對應當篇判斷的固定短標題。也不是把任何句子寫成否定轉折就算此模式。

## 帳號與當次任務

取回帳號／作者、定位與聲音、當次人群、素材、目的、有效CTA與交付深度。已知就用，核心缺口會改變主張才問。換帳號重新推導內容，不沿用原案例的節目、消費觀、價格、品牌杯子或分享對象。

已明確要求這套模式就直接執行；未選型的新輪播若有 carousel-mode-guide，先推薦適合模式。只要文案也仍採本模式的物件判斷與整組收束，不轉成通用故事稿。

## 先找到真的能重新理解的事

1. 從來源取一個常見判斷、被漏看的條件及作者的新標準。把必要限制寫清楚，例如「買來打算使用卻一直沒用」不等於否定收藏。
2. 選直接涉及這個選擇的日常品項。杯子用來喝、相機用來拍，使用結果可直接對應「有沒有獲得用途」。不要用水位象徵界線、橡皮筋象徵自私，讓讀者先猜比喻才懂主張。
3. 為前段鎖一對自然、簡短的左右標題，文字、位置及讀法跨張一致。右側可省略前句已交代的判斷，不為對仗重講全文。
4. 每張同一類主品項、兩種可見狀態。新物件帶來新的辨認，不必每張再發明一個新道理。只做大與小、多與少仍不足以完成重估，必須說得出哪個判斷被修正。

每個候選先檢查：不用 caption 能認出物件與用途嗎？左右差異真是這品項的使用、結果或條件嗎？標題直接判斷眼前這件事嗎？如果必須補人物故事或長解說才成立，換物件、改題或改用其他模式。

## 整篇要完成收束

前段反覆用不同品項支持同一標準；後段在圖片內完成「命名新標準 → 放回讀者生活 → 一個行動」。這是功能順序，不固定前三張比較、後三張文字或總共六頁。

固定左右標題適用前段比較卡。結論、價值觀和CTA頁可以轉成短文字版面，不硬保留兩欄，也不能因「單物件」把完整結尾刪掉。Caption 補來源、故事、方法與條件，不承擔挽救難懂圖片或補上全篇缺失結論的工作。

## 拍物件與排文字

製作圖片前讀 [製作與驗收](references/production.md)。基準是白底、單一主要品項的自然攝影、黑色短標題、充分留白。這是本模式，不能把另一模式的深色底或人物場景自動帶進來；使用者當次明示改外觀時依其要求。

先做一張確認標題、物件比例與文字位置，再展開。先生成無字物件，中文標題與必要標籤以可編輯文字排上；既有成品編輯依宿主影像工具規範。語意要先過，不能拿精緻攝影掩蓋對照不成立。

## 指令與交付

可直接說：「用 C01 你以為／其實單物件對照，依我提供的帳號、受眾與素材做一篇輪播。前段固定左右標題，讓物件狀態直接改變判斷；後段在圖內完成價值觀與分享CTA。先交選題、物件配對及逐頁稿。」

完整圖文任務交實際PNG、手機與整組預覽、圖上文案、caption、可編輯來源、無字素材與提示、來源及檢查紀錄。只做文案或分鏡則停在指定層，不把提示詞稱成品。修正後同步更新圖、文字與下載包。製作不包含發布、私訊或設定自動回覆。

驗收以物件和觀點的直接關聯、公平比較、固定標題、完整收束及實際手機可讀性為準。主責自查、使用者喜好、真人理解及發布成效分開，不能宣稱已驗證爆款。
