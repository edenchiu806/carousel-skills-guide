# 單物件對照：製作與驗收

## 同類物件，公平對照

同一張左右以同一品項、相近尺寸與機位作基準，讓使用狀態、功能、使用痕跡或實際結果承擔差異。不要偷偷更換品質、規格、比較基準再宣稱新判斷成立；尺寸本身就是題目時可以改，但要能直接說出這個差異為何改變判斷。

單物件指一個主要品項，不是任何情況都只准一件：要說明買一送一喝不完，右側可有兩杯同類咖啡。不能為守數量規則刪掉必要情境；也不加無關道具、人物、桌面與背景故事來填畫面。

物件狀態要符合日常。相機不靠套塑膠袋表示沒用，咖啡不套不合理包裝；使用過仍可乾淨、保養良好，不把破裂、發霉或不安全使用當成值得鼓勵的事。

## 必要標籤可以留下

少量價格、狀態或時間標籤可交代照片無法自行證明的條件，例如「一次也沒穿」。它定義本張創作情境，不證明照片裡的真實歷史，也不能用它補救物件與主張完全無關。

價格或優惠若是事實需查證並記錄日期與具體品項；若為示意設定就明示，不當成即時報價、正在進行的優惠或作者真實消費。品牌標記不代表合作或背書。原案例的價格與杯子都不是跨帳號預設。

## 對照之後還要給新標準

前段同一對標題重複，有助讀者把注意力留給物件。每張的新貢獻可以是另一個直接相關的日常選擇，不用硬塞教學或刻意改句型。

後段用短文字說清作者真正採用的標準，再給生活中的允許或選擇，最後是一個與前文一致的CTA。結論留在圖內；來源、細節與限制可由 caption 補足。沒有有效資源就不自造贈品，分享型CTA可指明適合收到的人。

## 版面

4:5直式可用1080×1350起步，實際平台和使用者要求優先。白底、黑色短標題、自然物件攝影，左右保留均衡留白。整組內容集中在畫面中段，檢查整組可見範圍的位置，不是把每行字都改成置中。

比較卡先鎖標題與物件區，再換品項。後段按閱讀功能安排大小字、字重、版心與留白，保留內部必要的左對齊；避免每行一樣粗大、均勻置中。相同字型家族可用不同字重，實際選可用字體，不分發未授權字型。

文字與物件分層保存。生圖比例、實物接觸、杯口、鏡頭蓋、衣物包裝及影子要看實際圖；不能只檢查提示或JSON。正常生成細節未核對前不宣稱精準幾何變換。

## 交付前逐項看

- 不靠caption就能認出主品項、兩種狀態及所判斷的日常行為。
- 讀者原本的判斷與新標準有實質差異，不只大與小的視覺變化。
- 前段固定標題一致，價格／狀態註記精簡、準確且符合情境。
- 兩邊比較公平；補充限制沒有否定前面的結論。
- 後段圖片已完成新標準、價值觀與行動，沒有只交比較清單。
- 全尺寸及手機大小都看過，字清楚、標題物件比例與留白合理。
- 原句、圖、caption、編輯來源及ZIP版本一致。

這些檢查不能代替真人理解或發布成效測試。
