# 輪播八模式補充安裝包 v1.1.0

這次將C01正式換成「你以為／其實單物件對照」，移除舊C01通用逐頁故事風格。C02到C08編號不變。包內有兩個技能：carousel-mode-guide負責選型；misconception-object-carousel負責C01詳細製作。其餘七種指南已自含，不需要原私人工作區。

## 任何可讀文字的AI

上傳「輪播八模式-通用完整安裝指令.md」，再說：

> 請把這份文件作為輪播製作補充規則。新輪播沒選模式時，先推薦兩三種讓我確認；已指定、延續成品或我請你決定時直接進行。C01是你以為／其實單物件對照。請如實說明這份規則能否永久保存。

單檔已包含兩個skill及全部指南；不支援永久知識的AI，只能在這次對話使用，不能宣稱已永久安裝。C01–C08是這份指南的模式編號，不是通用平台指令或八個AI模型。

## 支援技能資料夾的AI

把carousel-mode-guide和misconception-object-carousel兩個資料夾一起複製到宿主的技能根目錄，保持相鄰；不要只搬SKILL.md而漏掉references。agents/openai.yaml是可選介面資訊，其他宿主可忽略。

有Python3.9以上可執行：

```sh
python3 install.py --destination /你選定的技能根目錄 --dry-run
python3 install.py --destination /你選定的技能根目錄
```

只裝C01專門技能可加：

```sh
python3 install.py --destination /你選定的技能根目錄 --only misconception-object-carousel
```

上述路徑請換成真實目錄；含空白時加引號。安裝器不需要網路、第三方套件或API key。它先檢查整包完整性，拒絕符號連結及同名目錄，不覆蓋原技能或修改宿主設定。已安裝1.0.0者，請先將舊carousel-mode-guide移到備份位置，再安裝新版；不要合併殘留舊的c01-text.md。

## 接回既有工作流

在原輪播入口或專案指令加一句：

> 新輪播未選模式時，先讀carousel-mode-guide/SKILL.md，推薦兩三種並讓使用者確認；已指定、延續成品或授權AI決定時直接接入。指定你以為／其實單物件對照時用C01及misconception-object-carousel。只要文案是交付深度，不改變模式。

支援技能呼叫的宿主可用 $carousel-mode-guide；只做C01可用 $misconception-object-carousel。其他宿主請明確要求讀文件；資料夾複製成功不代表每個AI會自動啟用。

## 製作時怎麼說

- 還沒選：幫我做一篇輪播，題目是＿＿。先推薦兩三種適合模式，說明差別，等我選。
- 選C01：用C01你以為／其實單物件對照，依我提供素材設計固定左右標題與物件狀態，後段在圖內完成價值觀和CTA，先交文案與配對。
- 延續：沿用這篇C01，只調第三張的物件，保留標題與其餘文字。
- 直接做：依帳號、受眾與素材幫我決定模式，說明理由後直接做完整圖文。

實際生圖、查證與匯出依宿主工具；缺工具時只能交可完成的企劃、文案或分鏡，不能把提示詞稱成品。製作不自動包含發布、私訊或開啟自動回覆。包內不含私人記憶、來源庫、品牌資產、字型、登入或生圖服務；未在所有AI系統逐一實測。

## 驗收與移除

先試「請做輪播，還沒選模式」，應推薦並等選擇。再試「用C01，先交物件配對」，應固定左右標題、檢查物件與判斷的直接關聯，保留圖內收束。最後試「延續C03只改第三張」，應沿用而不重問八選一。

移除時刪除安裝的兩個技能資料夾與自行新增的入口指示。對話／知識庫版則移除上傳檔或專案規則。
